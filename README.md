# Fantasy Draft HQ

An educational fantasy football web app with:

- Draft Guide
- Demo Player Rankings
- Functional snake Mock Draft
- Live roster tracking
- DraftIQ real-time draft assistant interface

## Run locally

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for deployment:

```bash
npm run build
```

This project uses demo player data for a student project. It does not provide gambling or betting advice.
